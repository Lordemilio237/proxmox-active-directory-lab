# proxmox-active-directory-lab
# Projet Proxmox & Active Directory

## Présentation

Ce projet pratique a été réalisé dans le cadre de ma formation en systèmes, réseaux et cybersécurité. Il consiste à mettre en place un environnement virtualisé avec Proxmox et à découvrir l'administration centralisée d'un domaine Windows avec Active Directory.

## Objectifs du projet

* Découvrir la virtualisation avec Proxmox.
* Installer et configurer les services de domaine Active Directory (AD DS).
* Créer et gérer des comptes utilisateurs.
* Organiser les utilisateurs et les ressources avec des unités organisationnelles (OU).
* Créer et configurer des stratégies de groupe (GPO).
* Comprendre la gestion centralisée des utilisateurs et des paramètres de sécurité.

## Technologies utilisées

* Proxmox VE
* Windows Server
* Active Directory Domain Services (AD DS)
* Utilisateurs et ordinateurs Active Directory
* Group Policy Management (GPMC)

## Travaux réalisés

### 1. Virtualisation

Création et configuration de machines virtuelles dans Proxmox pour construire un environnement de laboratoire.

### 2. Active Directory

Mise en place d'un domaine Windows et découverte de l'administration d'un annuaire centralisé.

### 3. Gestion des utilisateurs

Création et organisation de comptes utilisateurs et de groupes dans Active Directory.

### 4. Unités organisationnelles (OU)

Création d'OU pour structurer les objets du domaine.

### 5. Stratégies de groupe (GPO)

Création et configuration de stratégies de groupe afin d'appliquer des paramètres aux utilisateurs ou aux ordinateurs.

## Documents du projet

Les comptes rendus des travaux pratiques sont disponibles dans les fichiers Word présents dans ce dépôt.

## Compétences développées

* Bases de l'administration Windows Server
* Notions d'Active Directory et d'AD DS
* Gestion des utilisateurs et des groupes
* Organisation des objets avec les OU
* Configuration des stratégies de groupe (GPO)
* Virtualisation avec Proxmox

## Bilan

Ce laboratoire m'a permis de mettre en pratique les bases de l'administration systèmes et de mieux comprendre le fonctionnement d'Active Directory dans un environnement virtualisé.
